# Короткая ипотечная анкета

## Цель

Кликабельный мобильный прототип по `tasks/mortgage-short-form/task.md`: человек рассчитывает ипотеку, оставляет короткую заявку и выбирает время звонка эксперта партнёра. Реальные банковские сервисы и отправка данных не подключены.

## Дизайн

- Палитра: белый `#ffffff`, фон `#f3f5f8`, текст `#152242`, вторичный текст `#68758c`, основной синий `#0468ff`, успешное действие `#178768`.
- Типографика: системный sans-serif; заголовки 28–32 px, основной текст 16 px, подписи 13–14 px. Числа с одинаковой шириной знаков.
- Компоновка: один мобильный столбец, выравнивание влево, основной CTA в нижней панели. На широком экране — мобильное окно шириной 430 px на нейтральном фоне.
- Характер: спокойный интерфейс недвижимости; голубая карточка расчёта, крупный платёж, простые поля, отчётливое выделение выбора. Без рекламных иллюстраций и повторяющихся декоративных карточек.
- Поведение: постоянная нумерация четырёх шагов, сохранение при возврате, ошибки рядом с полями, доступные радиокнопки, видимый фокус. Анимация только короткого перехода экранов и отправки, с учётом reduced motion.

```text
Калькулятор → Контакты → Планы → Финансы → Звонок → Успех
                1/4       2/4      3/4      4/4

┌────────────────────────┐
│ Назад     Анкета    2/4 │
│ ━━━━━━ ━━━━━━ ─── ─── │
│ Заголовок              │
│ Короткое пояснение     │
│ Вопросы и варианты     │
│                        │
│ [ Продолжить         ] │
└────────────────────────┘
```

Проверка замысла: это последовательный сервисный сценарий, поэтому номера обозначают реальные шаги. Платёж крупный только в калькуляторе, где его сравнение — основная задача. Анкета остаётся простой формой без лишних визуальных блоков.

## Продуктовые допущения

- «Для семейной ипотеки и новостроек» трактуется как одновременное выполнение обоих условий. При другом сочетании вопрос о консультанте скрыт и не включается в заявку.
- Время звонка выбирается на один из следующих трёх календарных дней по Москве, с 10:00 до 19:00. Точный график партнёра не задан.
- Имя, телефон и почта — вымышленные данные профиля. Даже в сценарии пустого профиля телефон известен: пользователь авторизован.
- Ставки 6% и 18% — учебные значения для интерактивного расчёта, не банковские предложения. Доступность программ не проверяется.
- Тексты согласий — пояснения поведения прототипа; юридические документы и конкретный партнёр требуют уточнения до реальной интеграции.
- Черновик хранится только в sessionStorage текущей вкладки. Демо-сценарии доступны в отдельной панели вне продуктового интерфейса и сбрасывают текущую заявку.

## Демо-сценарии

Данные из профиля; пустые имя и почта; ранее данное рекламное согласие; ошибка отправки с успешным повтором. Все переключатели находятся вне анкеты.
