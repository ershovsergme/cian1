# Проверка прототипа

Проверено 21 ноября 2026 года.

## Автоматические проверки

- `npm run check` — синтаксис клиентских модулей и сервера корректен.
- `npm test` — 9 тестов: контакты, условный подбор, доход и кредиты, исключение скрытых данных, необязательность рекламы, московские даты на границе года, недопустимые слоты, аннуитет и границы калькулятора.

## Проверка в браузере

Проверено в браузере Codex на настольной компоновке и мобильных размерах 390 × 844 и 320 × 700.

| Сценарий | Результат |
| --- | --- |
| Предзаполненный профиль → семейная ипотека, новостройка → помощь с подбором → доход и кредиты → звонок → успех | Пройден полностью, без рекламного согласия |
| Планы без выбранных ответов | Ошибки показаны рядом с тремя группами, фокус на первой |
| Есть кредиты, платёж пустой | Отправка шага остановлена; после заполнения можно продолжить |
| Пустой профиль | Имя и почта пустые, телефон сохранён и readonly; ошибки при продолжении |
| Неверная почта | Показана ошибка; после исправления исчезает |
| Перезагрузка после редактирования | Имя, почта и текущий шаг сохраняются |
| Рыночная ипотека, вторичное жильё | Вопрос о помощи с подбором отсутствует |
| Нет кредитов | Поле платежа скрыто, заполнение не требуется |
| Время звонка не выбрано | Отправка остановлена с подсказкой |
| Изменение контактов на последнем шаге | Возврат сразу к звонку, выбранное время сохранено |
| Согласие на рекламу уже дано | Рекламного checkbox нет |
| Диалог согласий | Открывается; Escape закрывает и возвращает фокус на кнопку |
| Ошибка отправки | Данные и выбранное время сохранены, повторная отправка успешна |
| Мобильные размеры | Нет горизонтального переполнения; форма прокручивается, основной CTA доступен |
| Консоль браузера | Ошибок и предупреждений при проверенных взаимодействиях нет |

При визуальной проверке платёж перенесён из прокручиваемой части калькулятора в закреплённую панель. Исправлен конфликт идентификатора поля телефона с оболочкой экрана: label теперь правильно связан с readonly-полем.

## Границы проверки

Реальные iOS/Android-устройства, виртуальная клавиатура, VoiceOver/TalkBack и интеграции с партнёром не проверялись. Их нет в локальном прототипе. Даты и правила проверены отдельно от браузера, включая переход года. `prefers-reduced-motion` отключает CSS-анимацию и переходы; отдельная проверка системной настройки не проводилась.
