# Устройство прототипа

## Назначение и объём

Мобильный кликабельный прототип сокращённой ипотечной анкеты для воркшопа Циана. Цель — помочь заинтересованному пользователю перейти от калькулятора к разговору с экспертом, не заполняя банковскую анкету. Реализовано задание `tasks/mortgage-short-form/task.md`; задания главной и аукциона не выполнялись.

## Технологии и окружение

- HTML, обычный CSS и JavaScript ES Modules, без внешних runtime-зависимостей.
- Node.js ≥20 для локального статического сервера и тестов. Проверено на Node.js 25.8.2 и npm 11.11.1 в macOS.
- `sessionStorage` для черновика в текущей вкладке. Очистка — через выбор демо-сценария.
- Нативный `<dialog>`, радиокнопки, checkbox и range; адаптивная высота `dvh` и CSS `:has()` требуют современного браузера.
- Шрифты — системные; иконки — встроенный SVG; внешние ресурсы и CDN не используются.

Выбран минимальный стек для автономного учебного прототипа. Подключение официального UI-kit или production-стека не требовалось: смысл `cian1` — сборка с нуля.

## Запуск

Из корня проекта выполнить `npm run dev`, затем открыть `http://127.0.0.1:5181`. Для другого порта: `PORT=5182 npm run dev`. Сервер слушает только localhost. Установка пакетов и сборка не нужны.

`npm run check` проверяет синтаксис модулей. `npm test` запускает встроенный Node test runner. Проверки не отправляют данные и не требуют сети.

## Поведение

1. Калькулятор: программа, тип объекта, стоимость, взнос и срок. Платёж всегда виден в нижней панели.
2. Контакты: редактируемые ФИО и почта, неизменяемый подтверждённый телефон.
3. Планы: срок покупки, наличие объекта, условная помощь в подборе.
4. Финансы: доход вручную или быстрым выбором; платёж по кредитам появляется только при наличии кредитов.
5. Звонок: три следующих дня по московскому времени, точное время, необязательное рекламное согласие. Согласие, данное раньше, повторно не запрашивается.
6. Подтверждение: дата, время, телефон и объяснение дальнейших действий.

Кнопка «Назад» сохраняет введённые значения. На последнем шаге можно открыть контакты и вернуться сразу к звонку. Ошибки показаны у соответствующих полей; фокус переводится на первую ошибку. Перед отправкой проверяются все шаги, включая актуальность даты. Скрытые ответы о подборе и платежах по кредитам исключаются из формируемой заявки.

## Ограничения

Это локальная имитация. Заявка не уходит партнёру, профиль не связан с аккаунтом Циана, реальная доступность времени не проверяется. Нет backend, авторизации, банковских API, загрузки документов или оплаты. Партнёр, юридические тексты, ставки и условия для настоящего сервиса требуют уточнения. Продуктовые допущения перечислены в `design.md`.
