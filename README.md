# cian1 · Короткая ипотечная анкета

Приватный учебный репозиторий для практики «Три репозитория». Стартовая точка — пустой проект без кода и дизайн-системы. Сравниваем результат работы агента с нуля с `cian2` — стек и UI-kit Циана — и `cian3` — полное рабочее место дизайнера.

Собран кликабельный мобильный прототип по заданию [«Короткая ипотечная анкета»](tasks/mortgage-short-form/task.md): калькулятор → контакты → планы покупки → финансы → время звонка → подтверждение заявки.

## Запуск

Нужен Node.js 20 или новее. Установка зависимостей и сборка не требуются.

```sh
npm run dev
```

Откройте [http://127.0.0.1:5181](http://127.0.0.1:5181). Другой порт: `PORT=5182 npm run dev`.

В меню **«Сценарии»** над мобильным экраном: предзаполненный профиль, пустые поля, ранее данное согласие на рекламу и ошибка отправки с повтором. Выбор сценария сбрасывает текущую заявку. Черновик сохраняется при перезагрузке этой вкладки.

Все данные вымышленные, отправка имитируется локально. Реальных API, банковских интеграций и передачи персональных данных нет. Расчётные ставки — учебные значения.
